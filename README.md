# ことば帳 · 日语语法语料库

面向日语学习者的本地语法知识库、句子语料库与词典工具。界面运行在本机浏览器中，Node.js 本地服务用于静态页面和 MDict 词典查询。目前用ai开发进度就是这样，ai没有额度了，代码公开了，希望有时间的大佬能继续完善。

## 启动

需要 Node.js 18 或更高版本。在项目目录首次运行：

```powershell
npm install
npm start
```

然后打开 <http://127.0.0.1:4173>。MDict 本地查询必须经此 Node.js 服务提供；若浏览器显示“Failed to fetch”，先确认终端中的 `npm start` 仍在运行，并确认访问地址是 `http://127.0.0.1:4173`，不要用 `file://` 或 VS Code Live Server 打开。按 `Ctrl+C` 停止本地服务器。服务器只绑定到本机回环地址。

Windows 用户也可以双击项目根目录中的 `start.bat` 快速启动。脚本会在缺少依赖时运行 `npm install`，启动本地服务并打开浏览器；如果服务已经运行，则直接打开页面。首次使用仍需先安装 Node.js 18 或更高版本。

### 配置 DeepSeek API

1. 首次运行 `node server.js` 时，程序会从 `api-config.example.js` 自动创建项目根目录下的 `api-config.js`。
2. 用文本编辑器打开 `api-config.js`，将 `apiKey` 的空字符串替换为自己的 DeepSeek API Key；需要时也可在同一文件调整 `baseUrl` 或 `model`。
3. 保存文件并刷新网页。设置页会显示配置的地址和模型；无需每次重新输入 Key。也可以点击“测试接口”检查配置。

`api-config.js` 已列入 `.gitignore`，避免误提交本地密钥；不要把 API Key 写进 `api-config.example.js`。该文件会由本地服务器提供给浏览器，因此密钥并非加密或隐藏：只在可信的本机环境使用，不要公开部署、共享该文件或让其他人访问本地服务。需要临时测试其他 Key 时，可在设置页输入；临时 Key 只保留在当前页面会话。

## 当前可用功能

### 语法与句子语料

- Grammar 可包含多个独立 Usage；可编辑接续、意义、分类、个人解释和备注。现有模型以教学语法和用法为核心，学校文法概念及其多对多关联尚待扩展。
- 手动添加、编辑、收藏句子，记录翻译、来源和备注。句子可关联 Grammar/Usage，并保存具体实例位置；外部来源、教材例句、自编例句和 AI 生成内容应清晰区分。
- 「外部资料」页可通过 Tatoeba 官方 API 搜索日语句子，并选择中文或英文译文；核对作者/许可证后逐条导入，保留日文、相应译文、出处、署名和许可证。语法资料支持从 Japanese Language Data 的公开语法 JSON 获取，也可预览并导入用户提供且有权保存的 JSON/CSV/TSV；导入后可在语法库按形式、等级、释义、接续及例句搜索。Japanese Language Data 的语法说明当前标记为 draft，未经母语者审校，仅作学习参考。BCCWJ、少納言、中納言、I-JAS 等需通过各自官方入口使用。
- 句子详情可调用已配置的 AI 生成中文翻译和讲解，编辑/确认后与来源模型和时间一起保存；此功能复用 AI 服务，不等于有道机器翻译 API。
- 句中 Grammar/Usage 实例可定位、高亮和反向查询；分析结果可由用户确认、修正或删除。
- 按 Grammar 或 Usage 查找关联句子；支持语法、句子文本、来源等搜索。
- 可选的 OpenAI Chat Completions 兼容接口，用于按现有语法候选分析句子。

### 语法体系整合目标（待实现）

后续扩展应在现有 Grammar、Usage、Sentence 和句中实例模型上增量实现，不重建整套数据模型，也不把日本語教育文法、学校文法和 JLPT 强行合并为一套分类。

- **教学语法**继续承载语法形式/别名、Usage、意义、接续、语境、语气、使用限制、近义/易混淆表达、JLPT 等级及其来源、典型例句和真实语料例句。一个 Grammar 可有多个 Usage，每个 Usage 可关联多个例句。
- **学校语法**增加独立的概念目录，至少支持词类、活用类型、活用形、助动词、助词、补助动词、句子成分及结构关系，并记录概念定义、例句、分析体系名称和来源。不同学校文法体系可以并存。
- Grammar/Usage 与学校语法概念应使用有明确含义的关联记录，例如“涉及”“由……构成”“对应”“易混淆”，支持双方反查；一个教学语法可关联多个学校语法概念，反之亦然。
- 句子类型应明确区分教材典型例句、外部真实语料、用户自编和 AI 生成。句子及译文可分别记录来源、原始 ID、URL、作者、许可证、版本、导入时间和审核状态；未知信息留空，不能臆造。AI 生成内容不得标记为真实语料。
- 语法详情目标展示核心意义、接续、典型例句及译文、真实语料与出处、学校语法分析、语境/语气/限制、易混淆表达、关联知识和个人备注；支持 Grammar → Usage → 例句，以及句子 → Grammar/Usage/学校语法概念的双向查询。语料可按来源、语法、用法和句子内容搜索，并能筛选缺少例句的语法。
- 上述学校语法概念、显式关联、体系来源、审核状态和语料许可字段属于**待实施目标**，不能误认为当前版本已经支持。

### 本地词典与词语关联

- 词典词条保存在浏览器 IndexedDB；Grammar、Usage、Sentence、Word 和来源元数据保存在 localStorage。
- 可手动创建、编辑、搜索词条，并加入或移出个人词库。
- 导入 JMdict XML、JSON、CSV、TSV，建立本地 IndexedDB 可搜索词条索引。CSV/TSV 支持表头字段映射；导入时记录来源名称、URL、版本、许可、原始词条 ID 和导入时间。
- JMdict XML 导入会预填 JMdict 来源与 CC BY-SA 4.0 许可信息。再分发 JMdict 数据时须遵守其署名与相同方式共享要求；请从合法来源取得词典文件。
- JMdict 官方资料入口：[项目说明](https://www.edrdg.org/jmdict/j_jmdict.html)、[EDRDG 许可](https://www.edrdg.org/edrdg/licence.html)、[官方英文压缩数据](https://www.edrdg.org/pub/Nihongo/JMdict_e.gz)。当前导入器接受 XML/JSON/CSV/TSV；官方 `.gz` 需先解压成 XML 文件再导入。
- 项目根目录的 `词典` 文件夹支持本地 MDict `.mdx` 精确查词；程序会递归识别同目录同名 `.mdd` 配套文件。查询在本地 Node 服务的隔离工作线程中运行，不上传或整本导入词典。不设 MDX 文件大小上限；词头按词块按需读取，不再启动时解压并缓存整本词头索引。非常大的词块或媒体资源仍会按其实际解压大小使用内存，若系统内存不足或文件损坏/不兼容，会显示读取错误。`.eudic` 欧陆专有格式不支持。
- 可一键搜索当前所选词典或全部本地 MDX；全词典查询只展示有匹配的词典，结果按词典分组且可折叠。部分词典查询失败时仍显示其他命中结果，并单独报告失败来源。
- 在句子中点选词语会自动查询当前本地 MDict；会依次尝试词面及有限的词形回溯候选。AI 分析生成的词语关联可通过“查词并确认”自动查询其原形候选，再确认关联。确认只把词头和词典来源关联到句子，不复制 MDict 释义到个人词库。
- 支持从配套 MDD 按需读取图片、音频、CSS、JS 和字体资源；若词典的 CSS 未打包进 MDD，也会读取同目录同名 `.css` 旁置样式表。不设单项资源大小上限；仅接受支持的资源扩展名，并对图片、音频和字体校验文件签名。词典完整 HTML/CSS/脚本在 `sandbox="allow-scripts"` 的隔离 iframe 中呈现，不授予同源权限；CSP 禁止网络 API 请求、外部资源、表单提交及嵌套框架，仅允许本地词典资源端点加载白名单媒体/CSS/JS/字体。CSS 样式会按需重写资源地址以保留原始排版；外部资源仍会被阻止。
- MDD 是配套媒体资源包，不含可独立检索的词头，不能单独导入为 Dictionary Entry。将同名 `.mdx` 与 `.mdd` 放在同一目录即可自动配对；缺少 MDX 时无法从 MDD 建立词库。
- 对查到的 MDict 词目，可经用户确认后逐条复制原始释义 HTML、纯文本和词头到本机 IndexedDB。来源记录包含文件相对路径、大小/修改时间指纹、配套 MDD 信息、用户填写的许可说明和个人保存确认时间。重复导入按稳定来源 ID 更新词典字段，保留收藏状态与个人备注；词典文件变化时提示用户，不自动覆盖本地副本。词典结果可打开句子表单，预填可识别的例句，由用户检查后保存；未识别到例句时可手工粘贴。
- 单条复制不是整本词典批量导入，也不会自动复制所有 MDD 媒体资源；商业词典内容请仅在相应许可允许范围内本机个人使用，不要将词条数据或词典文件未经许可导出、分享或再分发。
- 在句子详情中点选词语可查询本地词典，并把词形、原形候选及词条关联保存到句中；词条详情可反查关联句子。
- 词形回溯目前使用有限的词尾规则，只用于提供候选，需用户检查确认；它不是完整的日语形态素分析。
- 移除词典来源会删除该来源的词条并清除对应词条关联；用户语料和其他来源的数据不会因此删除。

### 练习与复习（本地 MVP）

- 可离线手动创建选择、填空和简答题，关联 Grammar/Usage；可编辑或从复习队列暂停题目。
- 配置 AI 后可按现有 Grammar/Usage 生成一道待确认题目；答案与选择项通过校验后才允许保存。AI 失败时保留人工建题入口。
- 每次作答都记录答案与正误；错题按题干和 Grammar/Usage 指纹去重，重复答错累加次数而不新增重复错题记录。
- 实现简单本地间隔复习：错题或“重来”1 天后复习；“记住了”逐步延长，用户可手动调整为较难/简单。可按到期、错题、全部筛选。
- 可展开查看单题最近 20 次作答记录；错题列表按 Grammar/Usage 汇总重复答错次数，展示前 5 个易错点。该统计只反映当前未解决错题，不会推断具体错误原因。
- 可手动保存自己的语法造句；配置 AI 后可评价指定 Grammar/Usage 是否合适、接续、自然度（1–5）并给出错误反馈和简短建议。AI 评价只作为建议。
- **题目、作答记录和造句 AI 评价会保存到本地**：题目需先由用户确认保存；每次作答提交后记录答案、正误和时间；AI 造句评价需点击“保存造句”后才与句子一起保存。句子评价包含 Grammar/Usage、接续判断、自然度、反馈、建议、模型和评价时间；JSON/CSV 备份中包含这些内容以及题目、作答和错题记录。
- **保存位置和限制**：以上数据保存在当前浏览器的 localStorage，不会自动同步到云端或其他设备。造句表单尚未保存时，句子和评价只是页面草稿；关闭或刷新后不会保留。每条句子目前只保存最近一次确认的 AI 评价，不保留历次评价版本。
- **AI 评价的不足**：仅按 Grammar/Usage、接续、自然度及模型返回的错误/建议做辅助判断，不保证语法解释或自然度判断正确，也不提供语料/词典出处；不能替代教师审校。语法片段定位可能失败，此时不会自动建立高亮关联，需要用户手动补充或修改。
- **练习与复习尚未实现**：简答题答案只做文本标准化后的精确匹配（支持用 `|` 分隔多个标准答案），不是语义判分；答错后不会由 AI 针对错误生成个性化讲解；尚无错因分类和个性化薄弱点诊断；间隔复习是简单规则，不是成熟或可配置的 SM-2 算法。也未实现从个人语料自动组卷、AI 例句一键保存到目标 Usage、批量生成与审核。

### 数据备份

- 完整 JSON 和 CSV 备份包含 Grammar、Usage、Sentence、语法/词语实例、Word、词典来源和词典词条，以及练习题、每次作答记录、错题状态和已保存的造句 AI 评价。
- JSON/CSV 导入按记录 ID 合并：相同 ID 的记录由导入内容更新，未出现在文件中的本地记录保留。
- 语法、语料、练习和复习数据保存在当前浏览器的 localStorage，词典词条保存在 IndexedDB；不会自动同步。清理浏览器网站数据前，请先导出完整 JSON 备份。
- CSV 使用 `type,id,data_json` 格式，每行的 `data_json` 保存一条完整记录。

## AI 配置与隐私

DeepSeek 的长期 API 配置位于项目根目录 `api-config.js`；详细设置步骤见上方“配置 DeepSeek API”。点击设置页的“测试接口”会发送一个只要求返回 `{"ok":true}` 的小请求。

长期 API Key 保存在本机的 `api-config.js`，临时输入的 Key 只保存在当前页面会话中。AI 请求直接从本机浏览器发送到 DeepSeek，不经过本应用服务器；服务商须允许来自 `http://127.0.0.1:4173` 的浏览器跨域请求。句子分析发送当前句子、按文本匹配筛选出的最多 50 个 Grammar 候选，以及最多 80 个本地词典候选；AI 提供词形、原形和语法关联建议，但不会自动保存到词库，所有结果都需用户审核。练习题也需用户确认后保存；造句 AI 评价仅在用户保存造句时写入该句子的本地记录，未保存的表单草稿不会跨刷新保留。

仅向你信任的服务商提供 API Key。不要将密钥发送到聊天、截图或提交到代码仓库；如果密钥意外泄露，请立即撤销并重新生成。此前在聊天中提供过的 API Key 应先撤销，再在 `api-config.js` 中填写新 Key。

## 第三阶段剩余路线图

第三阶段目标是在现有本地 Grammar/Usage、Sentence、Word、词典导入和 AI 句子分析能力上，补齐可授权的数据接入与个人复习闭环。仍坚持单用户、本地优先、可导出；不包含云同步、多人协作或社交功能。M1、M3、M4、M5 已有部分本地能力；M2 已有 AI 翻译讲解、Tatoeba 语料查询、Japanese Language Data 语法资料接入及结构化语法资料导入能力，专门的有道翻译 API 尚未实现。语法体系与例句增强目标也纳入本路线图，当前学校语法概念层、多对多关联及相应反查界面尚未实现。以下记录现状、剩余范围与验收标准。

### M2 外部资料使用与待提供文件

- **Tatoeba**：使用官方公开只读 [API](https://api.tatoeba.org/openapi) 查询日语句子；官方 [使用条款](https://tatoeba.org/en/terms_of_use) 说明句子按条目带有 Creative Commons 许可且署名是 CC BY 内容的重要条件。应用目前只保存许可恰为 `CC BY 2.0 FR`、已审核且有作者的日语句子；译文可选中文或英文，另存译者、译文许可证和来源链接。导出/再分发时必须继续遵守各条目的许可与署名要求。语料内容由社区贡献，准确性不作保证。
- **Japanese Language Data 语法资料**：外部资料页可获取公开的 `data/grammar/grammar.json` 和版本信息，确认后导入 Grammar/Usage。上游仓库：[jkindrix/japanese-language-data](https://github.com/jkindrix/japanese-language-data)，许可：[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。应用保存 URL、版本、许可及原始 ID。上游说明 595 条语法项目为原创整理，当前全部标记 `draft`，未经母语者审校；仅作学习参考，错误可在本地编辑。
- **OpenJLPT、日本語文型データベース、はごろも**：列为 M6 优先调查对象，不表示已经接入。实施前逐源核对官方数据格式、下载/API 可用性、许可及是否允许本地保存/再分发；仅在授权清晰时实现导入或查询。许可、格式或访问条件不明时，只保留官方链接并说明阻塞原因，不得虚构接口或抓取普通网页。
- **JMdict 词典**：词典页支持将 JMdict XML 导入 IndexedDB 并建立可搜索的本地索引。官方入口：[JMdict 项目说明](https://www.edrdg.org/jmdict/j_jmdict.html)、[EDRDG 许可](https://www.edrdg.org/edrdg/licence.html)、[官方压缩 XML](https://www.edrdg.org/pub/Nihongo/JMdict_e.gz)。`.gz` 文件需先解压为 XML 再导入；使用或再分发时遵守 CC BY-SA 4.0 的署名与相同方式共享条件。
- **其他日本語教育语法资料**：仍可通过结构化文件导入 JSON、CSV 或 TSV，并在导入前核对来源名称、官方 URL、版本（如有）及许可证/利用条件。JSON 格式示例：

  ```json
  {
    "source": {
      "name": "资料名称",
      "url": "https://example.org/grammar-data",
      "version": "2026-01",
      "license": "请填写真实许可证或利用条件"
    },
    "grammars": [{
      "id": "source-grammar-id",
      "name": "语法项目",
      "jlpt": "N3",
      "educationCategory": "条件",
      "connection": "接续",
      "usages": [{
        "id": "source-usage-id",
        "name": "用法名称",
        "meaning": "核心意义",
        "explanation": "说明",
        "connection": "用法接续"
      }]
    }]
  }
  ```

  CSV/TSV 采用表头列：必需 `name`；可选 `grammarId,jlpt,variants,connection,type,educationCategory,schoolCategory,usageName,meaning,explanation,usageConnection,sourceName,sourceUrl,sourceVersion,license`，每一行代表一个语法或 Usage。请勿把不允许复制/本地保存的商业教材内容放入文件；仅有网页地址并不等于获得复制许可。确认某一具体资料源后，可再评估合法的在线 API/下载适配器。

### M6 实施顺序与项目检查要求

开始 M6 编码前，先按实际代码检查并提交检查报告与实施计划，不要仅根据本文推断当前实现：

1. 核实 Grammar、Usage、Sentence 和句中语法实例的真实数据结构。
2. 核实 JSON/CSV 导入导出、去重和 ID 生成方式。
3. 核实导航、语法/句子详情、外部资料页面的现有交互。
4. 核实 localStorage/IndexedDB 数据结构、迁移机制及自动化测试覆盖。
5. 核实 AI 分析的语法候选检索和匹配流程。

分阶段交付：

1. **检查与设计**：报告现有结构、兼容性风险、迁移策略、测试方法和实施计划，再开始修改。
2. **关联模型**：新增独立学校语法概念及 Grammar/Usage 到概念的多对多关联；关联类型须有可读定义（如“涉及”“由……构成”“对应”“易混淆”）。概念记录分析体系名称、定义、例句及来源，允许不同学校文法体系并存。
3. **首个授权数据源**：先验证官方格式和许可；完成可预览、明确展示来源/许可、用户确认后导入的闭环。OpenJLPT 可作为优先候选，但须以实际可验证的源文件/API 和许可为准。
4. **例句与查询**：完善教材典型例句、真实语料、用户自编、AI 生成等类型标记；保存可得的翻译/来源/作者/许可/原始 ID/版本/导入时间/人工审核状态；提供 Grammar → Usage → 例句和例句 → Grammar/Usage/学校语法的反查，以及按来源和知识点搜索、缺少例句筛选。
5. **扩展数据源**：仅在各来源许可明确后接入日本語文型データベース、はごろも或其他 Provider。普通网页可查询不等于允许抓取、存储或再分发。

数据模型要求：保留教学语法（Grammar/Usage）与学校文法概念两套独立体系；例句可关联 Usage，不把多种例句来源混为一类。JLPT 等级和其他分类需保留来源及参考属性。未知的作者、许可、译文来源或出处必须留空，不得编造；AI 生成例句不得标为真实语料。

兼容要求：保持本地优先、单用户和现有数据；无需清空浏览器存储。Schema 扩展必须向后兼容并提供迁移，先验证备份/恢复。JSON/CSV 备份须覆盖新概念、关联及语料来源/许可证字段。导入失败、取消、坏文件或存储失败时不得部分覆盖现有数据。重复判断优先使用稳定的 source ID + original ID，不只按显示名称；不得覆盖用户解释、笔记、收藏和已确认关联。所有 AI/外部写入须由用户确认；不得将密钥、个人数据或整套本地词典上传到未经用户同意的服务。

M6 验收必须覆盖：一 Grammar 多 Usage、一 Usage 多例句、一 Grammar 多学校语法概念、学校概念反查 Grammar/例句、例句类型区分、来源/许可证/原始 ID 导入导出往返、重复导入保护个人数据、取消/错误文件/写入失败保持数据、离线且无 AI Key 的原有功能可用。交付实际测试结果、修改文件清单、迁移说明和未完成事项；先完成可验证的最小闭环，不重写整套应用或引入不必要框架。

### P0 全阶段验收

1. 新用户在无 API Key、无网络时，仍可手动添加/编辑句子、词条、Grammar/Usage、例句和练习题；可手动标记答案、写错误说明并安排复习。
2. AI/外部源的所有写入都必须经用户确认；AI 或同步不得覆盖用户手写解释、答案、备注、例句或已确认关联。
3. JSON/CSV 完整备份须覆盖新增词典来源、语料、形态实例、生成内容、题目、答题历史、错题项和复习计划；导入导出应通过往返验证。
4. 每个 P0 里程碑均需有成功、取消、重复导入/保存、损坏输入和失败恢复的测试；用户已有本地数据在任一失败路径下不得丢失。
5. 外部数据必须满足其许可与访问条件；无法确认合法使用方式或没有稳定接口的资源不能列为“已接入”。当前已实现的本地复习 MVP 不等于 M1–M3 或 M4–M5 全部完成。

### AI 失败与人工兜底（适用于所有里程碑）

- **配置/授权失败**：缺少 API Key、HTTP 401/403 或模型不可用时，明确提示具体原因和检查项；不自动反复请求，不清除用户已填写的内容。
- **网络/限流/服务错误**：超时、断网、HTTP 429/5xx 时保留当前句子、答案或编辑草稿；提供用户主动重试和稍后继续，不把失败伪装成成功，也不自动重复产生收费请求。
- **格式/校验失败**：AI 返回空内容、非 JSON、缺字段、无效索引或置信度不合法时，不保存该批结果；显示错误并允许重试或切换人工编辑。
- **低置信度/判断争议**：将结果标为待确认；用户可以接受、修改、删除或完全跳过。答案判定有歧义时允许用户自行判分并记录理由，不把 AI 评分当作不可修改的事实。
- **无 AI 仍可学习**：手动建立词语/语法关联、编写例句和题目、设置正确答案与解释、作答、记录错题及复习日期都必须有本地操作入口；断网不阻断核心复习。
- **重复与历史**：错题去重只合并错题队列实体，不覆盖每次作答记录；人工移除错题不删除原始题目或学习历史。

### P1 / P2（不阻塞第三阶段 P0）

- **P1**：Grammar 辨析与上下文题、薄弱知识点分析、学习统计、前置知识图、正式 Provider 扩展接口、XLSX、标签和自动学习计划。
- **P2**：更复杂的相似题去重、更完整知识图谱、高级 AI 学习路径、更多第三方语料源和词典格式。

所有外部语料、词典和在线资料都必须先核实许可与访问条件。应用不会抓取商业词典或绕过网站限制；云同步与账号系统不在本阶段范围内。
